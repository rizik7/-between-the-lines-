# Between the Lines

Сайт книгарні романтичної літератури.

**Живий сайт:** https://ВАШ_ЛОГІН.github.io/between-the-lines/

## Можливості
- каталог книг за категоріями, акції, відгуки
- блок «Книжковий клуб» із тарифами
- форма зворотного зв'язку
- адаптивна верстка, бургер-меню, CSS-анімації

## Технології
HTML, CSS (Flexbox, Grid, змінні, transition, @keyframes)
